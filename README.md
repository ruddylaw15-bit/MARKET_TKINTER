# MARKET TKINTER

Sistema de gestión de mercado y ventas desarrollado en Python utilizando Tkinter para la interfaz gráfica y SQLite3 como base de datos.

## Requisitos e Instalación

Para ejecutar este proyecto es necesario contar con Python instalado y ejecutar los siguientes comandos en la terminal para instalar las dependencias requeridas:

```bash
pip install db-sqlite3
pip install ttkthemes
pip install pillow
pip install tkcalendar
pip install reportlab


Aplicación

Para la base de datos usamos DB Browser for SQLite.
